# 06 — Full-Stack Analytics Web Dashboard (TerraPulse-Style)
Post-flight interactive analysis platform (**FastAPI** backend + **React + TailwindCSS + ECharts + Deck.gl** frontend).
- Drag & drop `.csv`, `.tlog`, and `.bbl` files.
- Runs `cansat_core` 4-stage validation + 3 `.onnx` neural networks.
- Auto-generates scientific conclusions, PDF/PNG exports, and 3D `.kml` for Google Earth Studio.
